# instagram-medija

Tiltas tarp kompiuterio ir Instagram.

Instagram API nemoka paimti failo iš kompiuterio — jam reikia viešo interneto adreso.
Šita saugykla tą adresą ir duoda: įkeltas failas iškart pasiekiamas per GitHub Pages.

## Adresas

```
https://<vardas>.github.io/instagram-medija/<failas>
```

## Kas čia dedama

Tik tai, kas skelbiama į Instagram — skaidrės, nuotraukos, video viršeliai.
Juodraščiai, šaltiniai ir asmeniniai failai lieka asistento projekte.

Saugykla vieša. Viskas, kas čia patenka, matoma visiems internete.

## Kaip veikia

tokie, kokie yra.
